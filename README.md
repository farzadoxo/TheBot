# What is TheBot?
I'ts a modern discord activae developer badge keeper written by python and [Discord.py](https://github.com/Rapptz/discord.py).
# How to use?
1. clone this repository using this command :
```bash
git clone https://github.com/farzadoxo/TheBot.git
```
2. set token at `.env` file like this ==> `TOKEN = "your token"`
   
3. also you can customize embed text and etc .

4. if you have docker on your machine only create a docker image from `Dockerfile` using these commands and run it :
```bash
cd /TheBot/src
docker build -t thebot .
docker run --rm -p 8009:8009 thebot
```
5. if you dont have docker or you wanna to run script directly on your machine follow this steps:
- install package and moduls using this command `pip install -r requirements.txt`
- run `bot.py`
6. add bot to a server and use /help command.
7. after 48h go to [Active Developer Badge](https://discord.com/developers/active-developer) and take your badge 🎉
